# Kataxone

MVP: 3D-карта потока создания ценности (КПСЦ).

## О проекте

Интерактивное приложение для визуализации и оптимизации производственного потока VENIO-C.

- **3D-тур** — панорама производственного цеха (Pannellum) с точками интереса по этапам потока.
- **Редактор КПСЦ** — интерактивная карта потока на React Flow: перетаскивание этапов, добавление/удаление узлов, редактирование параметров (время цикла, загрузка, стоимость) и создание связей.
- **Дашборд «До/После»** — сравнение текущего и целевого состояния потока, автоматический пересчёт метрик и экспорт плана улучшений.
- **Авторизация** — базовая форма входа с согласием на обработку персональных данных (ФЗ-152) и защищёнными маршрутами.

## Технологии

- [React](https://react.dev) + [Vite](https://vite.dev)
- [React Flow](https://reactflow.dev) — редактор графа КПСЦ
- [Pannellum](https://pannellum.org) — 3D-панорама
- [Zustand](https://zustand-demo.pmnd.rs) — управление состоянием
- [React Router](https://reactrouter.com) — маршрутизация
- [lucide-react](https://lucide.dev) — иконки

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется по адресу, который выведет Vite (по умолчанию `http://localhost:5173`). Первой откроется страница входа.

### Другие команды

```bash
npm run build     # production-сборка
npm run preview   # предпросмотр собранной версии
npm run lint      # проверка кода (oxlint)
```

## Бэкенд

REST API на Python: аутентификация и хранение графов КПСЦ.

### Технологии

- [FastAPI](https://fastapi.tiangolo.com) — веб-фреймворк
- [SQLite](https://www.sqlite.org) — база данных
- [SQLAlchemy](https://www.sqlalchemy.org) — ORM
- [JWT](https://jwt.io) — авторизация по токенам (`Authorization: Bearer <token>`)

### Запуск

```bash
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload
```

Сервер поднимется на `http://127.0.0.1:8000` (интерактивная документация API — `/docs`).

## Инструкция пользователя

### 1. Создание учётной записи

Форма регистрации в интерфейсе пока не предусмотрена, поэтому пользователь создаётся через API. Это можно сделать в Swagger-документации `http://127.0.0.1:8000/docs` (метод `POST /api/register`) либо через терминал:

```bash
curl -X POST http://127.0.0.1:8000/api/register \
  -H "Content-Type: application/json" \
  -d '{"username": "demo", "password": "demo"}'
```

### 2. Вход в систему

Откройте приложение (`http://localhost:5173`) — появится страница входа.

- Введите логин и пароль созданного пользователя.
- Отметьте согласие на обработку персональных данных (ФЗ-152).
- Нажмите **«Войти»**. При неверном пароле появится сообщение об ошибке.

После входа вы попадёте в 3D-тур. Выход — кнопка **«Выйти»** в шапке.

### 3. 3D-тур (главная страница)

- **Осмотреться** — перетаскивание мышью; **масштаб** — колесо мыши.
- Точки интереса (этапы потока) показаны на панели слева и пульсирующими метками прямо в панораме. Клик по метке или по пункту списка плавно поворачивает камеру к нужному этапу.
- Кнопка **«Перейти в Цех 2» / «Вернуться в Цех 1»** переключает панорамы.
- Карточка активной точки показывает название, загрузку и время цикла этапа.

### 4. Редактор КПСЦ (страница «Редактор КПСЦ»)

- **«До» / «После»** — переключение между текущим и целевым состоянием потока.
- **«Добавить этап»** — добавляет новый узел в конец цепочки.
- **Клик по узлу** — открывает окно редактирования: название, время цикла, загрузка, стоимость. Кнопка **«Сохранить»** применяет изменения.
- **«Показать в 3D»** (в окне редактирования) — закрывает окно и переводит в 3D-тур, фокусируя камеру на выбранном этапе.
- **Перетаскивание узла** — меняет его положение; **соединение** — потяните из точки на краю узла к другому узлу, чтобы создать связь.
- **Delete / Backspace** — удалить выделенный узел или связь.
- **«Сбросить»** — возвращает текущую версию потока к исходному виду.
- **«Сохранить на сервер»** — сохраняет текущую версию («До» или «После») в базе данных.

При входе в редактор граф автоматически подгружается с сервера (если он ещё не сохранён — используются данные по умолчанию).

### 5. Дашборд «До/После»

- Сверху — ключевой показатель сокращения времени протекания и расчётная **экономия в рублях**.
- **Ключевые показатели** — сравнение «До» и «После» по этапам, времени цикла и доле добавленной ценности.
- **Быстрая симуляция** — для каждого узкого места (загрузка > 90%) есть ползунок. Изменяйте время цикла — метрики и экономия пересчитываются на лету.
- **«Скачать план улучшений»** — выгружает текстовый файл со списком задач по оптимизации узких мест.
- Данные дашборда синхронизированы с редактором: все правки этапов сразу отражаются здесь.
